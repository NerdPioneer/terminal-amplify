# VPC Setup and Configuration

**Date:** September 1, 2025  
**Topic:** AWS VPC Configuration  
**Duration:** 2 hours

## Overview
Custom VPC for the terminal-journal project, with public and private subnets, an internet gateway, a NAT gateway, Lambda security groups, and VPC endpoints for S3.

## Configuration
- Custom VPC with public and private subnets
- Internet gateway and NAT gateway
- Security groups for Lambda functions
- VPC endpoints for S3

## Notes
- VPC endpoints keep S3 traffic on the AWS network and avoid NAT data-processing charges for that path
- Private subnets have no route to an internet gateway; outbound internet from those subnets goes through the NAT gateway
- Security groups are stateful and limited to the required ports and sources
